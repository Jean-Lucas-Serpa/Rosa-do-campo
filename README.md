# Rosa do Campo Agropet — Site Institucional

Site institucional de página única para a **Rosa do Campo Agropet**, loja de produtos para pets (rações, remédios, alimentos e acessórios) localizada em Penha, SC, atendendo Penha e Balneário Piçarras.

## Sobre

- **Tipo:** Landing page institucional (não é loja virtual, sem carrinho de compras)
- **Formato:** HTML único, sem dependências externas de build
- **Identidade visual:** Paleta extraída da logo oficial (coral, dourado e marrom terroso)

## Seções

- Hero com foto de destaque
- Categorias de produtos
- O que a loja vende (rações, remédios, petiscos, higiene, acessórios)
- Produtos em destaque (fotos reais)
- Por que escolher a loja
- Depoimentos reais de clientes (Google)
- Galeria de clientes pet
- Visite a loja (fachada, endereço, WhatsApp, Instagram e mapa incorporado)
- Grupo de promoções no WhatsApp

## Recursos técnicos

- 100% responsivo (mobile, tablet, desktop)
- SEO local otimizado (meta tags, Open Graph, dados estruturados `PetStore` do schema.org)
- Botões de WhatsApp com mensagem pré-preenchida
- Animações de entrada e transições suaves ao rolar a página
- Sem frameworks — HTML, CSS e JavaScript puro
